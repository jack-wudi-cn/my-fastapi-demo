# 市场需求文档 (MRD) - Invoice-AI MVP

## 1. 业务痛点
- **人工核验效率低下且易出错**：面对大量的非结构化发票文本，财务人员需逐字核对并录入，高强度工作下极易发生肉眼视觉疲劳，导致大额发票录入错误，引发财务风险。
- **合规与风控盲区**：传统的报销流程高度依赖人工记忆或事后抽查，难以彻底杜绝“同一张发票重复报销”等违规行为，导致企业资金流失。

## 2. 目标用户
- **主要用户**：一线财务专员（负责日常发票的初步审核与数据录入）。
- **次要用户**：财务主管/风控审核员（负责大额或异常单据的最终复核与决策）。

## 3. 核心商业价值
- **降本增效**：将财务从繁琐的机械化录入中解放出来，预期单张单据处理时间缩短70%以上。
- **风控闭环**：通过系统自动校验“重复报销”与“大额预警”，实现100%的机审拦截，降低企业财务合规风险。

## 4. 竞品/现状分析
- **现状**：目前多数企业依赖传统 ERP 系统或纯手工 Excel 处理，只能完成“记账”，无法在前端进行“智能提取与业务拦截”。
- **差异化优势**：本产品引入“AI 智能提取 + 规则引擎校验”双核模式，不仅解决录入问题，更前置了风控防线。
